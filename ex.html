Экспорт ​

Тест-кейсы и чек-листы можно выгрузить в файл xlsx. Кнопка «Экспорт» находится на панели действий над таблицей в разделах «Кейсы» и «Чек-листы». Она доступна всем, у кого есть доступ к разделу. Для кнопки «Импорт», в отличие от неё, нужно право на редактирование.

Шаг 1. Выберите, что выгружать ​

Объем выгрузки определяется тем, что отмечено в таблице:

  1. Отмечены чек-боксы (цифра 2) — выгружаются только отмеченные элементы и папки.
  2. Ничего не отмечено, но открыта папка — выгружается содержимое текущей папки.
  3. Ничего не отмечено и папка не выбрана — выгружается вся вкладка.

Внимание

Экспорт всегда учитывает активные фильтры и поисковый запрос: выгрузится только то, что попало в выдачу таблицы. Чтобы выгрузить всё, сначала сбросьте фильтры и очистите поиск.

Шаг 2. Нажмите «Экспорт» ​

Нажмите на кнопку «Экспорт» (цифра 1). Начнется загрузка xlsx-файла.

Результат ​

Файл называется по шаблону Проект_Пространство_дд-мм-гг.xlsx, например Альфа_Смоук_16-07-26.xlsx.

Заголовки колонок в файле — на английском языке. Для тест-кейсов выгружаются колонки:

КолонкаЧто в ней
Numberпорядковый номер строки в выгрузке
IDидентификатор тест-кейса
Pathпуть по папкам, включая проект и пространство
Titleназвание
Creatorавтор
Creation dateдата создания
Priorityприоритет
Statusстатус
Keysтеги
Descriptionописание
Parametersпараметры
Preconditionsпредусловия
Postconditionsожидаемый результат тест-кейса
Attachmentsссылки на вложения
Stepшаг
Expected resultожидаемый результат шага
Test dataтестовые данные шага
Automation statusстатус автоматизации
Autotestсвязанный автотест
Attributesатрибуты

Один тест-кейс занимает столько строк, сколько в нем шагов: первый шаг попадает в строку самого тест-кейса, каждый следующий — в отдельную строку, где колонки тест-кейса пустые.

Выгрузка чек-листов устроена так же: один чек-лист занимает столько строк, сколько в нем чеков. Отличаются только колонки — вместо Preconditions, Postconditions, Step, Expected result, Test data, Automation status и Autotest в ней две: Check number (номер чека) и Check (текст чека).

Выгруженный файл можно загрузить обратно в DoQA: при импорте выберите источник «DoQA».
